# Auto-Cut Blight (rimhunter)

A RimWorld 1.6 and 1.7 mod that designates blighted plants to be cut on its own and sends colonists to cut them first. It is written from scratch by rimhunter. The idea comes from the original Auto-Cut Blight; no code, asset or build of the original was read, copied or used. It needs no Harmony and no other mod.

## Bugs

Report bugs at [github.com/rimhunter/auto-cut-blight/issues](https://github.com/rimhunter/auto-cut-blight/issues), with your log file.
